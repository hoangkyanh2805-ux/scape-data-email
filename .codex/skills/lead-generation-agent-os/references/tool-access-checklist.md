# Tool Access Checklist

Use this before claiming that a pipeline can run live. If access is missing, create draft artifacts and list what is needed.

## Universal Tools

- Workspace or table store for source maps, candidate tables, outreach batches, lead dashboards, and daily reports.
- Browser or web search for public source discovery and verification.
- File storage for renders, PDFs, screenshots, and exported tables.
- Logging destination for run notes, approvals, costs, and stop reasons.

## Pipeline 1: Digital Product Leads

Needed for draft mode: product/page text, offer details, checkout URL, target market notes.

Needed for evidence mode: platform access or scrapers for Reddit, YouTube, TikTok, Facebook groups, forums, Discords, or other named communities.

Needed for creative mode: image/video generation tool access if assets should be generated, or ability to draft prompts if not.

Needed for live mode: ad platform or Whop/ads dashboard access, conversion/revenue reporting, approved daily budget, approval to launch or edit campaigns.

Do not proceed live unless conversion event, destination URL, budget ceiling, and claim compliance are explicit.

## Pipeline 2: Physical / Local Leads

Needed for draft mode: trade, city/area, batch size, qualifier, target buyer type.

Needed for candidate mode: property records, business listings, permit records, satellite/street-view/listing imagery, or another public source selected for the trade.

Needed for render mode: reference images and approved image-edit/generation access.

Needed for outreach prep: address/email/phone validation, page builder or landing page system, tracking links/QR generation, postcard/email/SMS provider details.

Needed for live mode: explicit approval for paid imagery, render generation at scale, page publishing, postcard purchase, email/SMS send, and follow-ups.

Do not use imagery older than three years unless the user accepts stale-data risk for that batch.

## Pipeline 3: Lead Resale

Needed for draft mode: captured lead table, trade, city/area, sample lead count, pricing assumptions.

Needed for business discovery: Google Places or another business listing source, coverage area evidence, franchise filter criteria.

Needed for sample assets: PDF/page creation, render access, redaction rules.

Needed for live mode: approval to send business outreach, share lead details, set pricing/exclusivity, receive payment, and mark lead sold.

## Access Report Format

- Tool/service: <name>
- Purpose: <step it enables>
- Access status: available / missing / unknown / approval needed
- Cost risk: none / low / medium / high
- Data risk: none / personal/contact / private/community / payment
- Safe fallback: draft only / manual import / ask user / stop
