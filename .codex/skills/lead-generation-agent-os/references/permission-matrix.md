# Permission Matrix

Default rule: if an action affects money, customer-facing output, production data, access control, privacy, or irreversible state, stop for human approval.

| Action | Agent may do autonomously | Human approval required | Evidence required |
|---|---:|---:|---|
| Read supplied product pages, docs, tables, and public pages | Yes | No | Source URL/path |
| Draft profiles, tables, prompts, pages, PDFs, copy, and reports | Yes | No | Draft artifact |
| Scrape public data within approved tools and quotas | Yes | Sometimes | Source, date, quota/cost |
| Access private or restricted communities | No | Yes | Community, access method, purpose |
| Use paid APIs at small pre-approved limits | Yes | If limit not approved | Cost estimate and ceiling |
| Pull paid imagery, generate media at scale, or buy postcards | No | Yes | Batch count and cost |
| Send email, SMS, postcards, DMs, or follow-ups | No | Yes | Sample, recipient count, compliance checks |
| Publish landing pages or property pages | No | Yes | Page preview and tracking plan |
| Launch ads, change ad budget, or pause live ad sets | No | Yes | Campaign draft, budget, reason |
| Contact abandoned checkouts or visitors | No | Yes | Consent basis and message |
| Share full lead details with a business | No | Yes | Lead list, recipient, terms |
| Mark a lead sold or exclusive | No | Yes | Buyer, territory, price, timestamp |
| Delete records or overwrite tables | No | Yes | Backup and exact target |

## Forbidden Without Explicit User Direction

- Inventing contact data or property facts.
- Sending mass outreach without approval.
- Making unsupported income, health, legal, finance, or guaranteed-result claims.
- Selling exclusive leads to more than one business.
- Hiding uncertainty or treating review rows as approved.
